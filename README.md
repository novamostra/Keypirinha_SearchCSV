# Keypirinha_SearchCSV
The Search CSV package for Keypirinha enables searching within any CSV file and retrieving specific results directly to the clipboard.

Using a CSV file generated from [Mockaroo.com](https://www.mockaroo.com/) with columns id,first_name,last_name,email,gender,phone_number,company PhoneBook searches in first_name and last_name for the text entered in the launcher and displays a list of possible matches. When a match is selected, the phone_number value is copied to the clipboard. Everything is fully configurable through properties, requiring no code modifications.
